# 2026年11月 米国市場スイングカレンダー

S&P500、米国個別株、ETF、インデックスファンドをスイングトレードするときに、2026年11月の予定と、その市場コンセンサス、S&P500への典型的な影響を PC で確認する静的サイトです。

株価やニュースの生配信はありません。画面は日本語です。カレンダーのマスは日本時間の日付で、各予定に日本時間、米国市場日、東部時間を併記します。

## 使い方

ブラウザで `docs/index.html` を開きます。左が月グリッド、右が詳細です。日を選ぶと、その日の予定が出ます。Anthropic IPO は日付未確定のため、グリッドの上に常時表示します。

ローカルで見る場合は、`docs/` を配信します。`file://` では月ファイルを読めません。

```bash
cd docs
python3 -m http.server 8080
```

ブラウザで http://127.0.0.1:8080/ を開きます。

GitHub Pages で公開する場合は、`main` ブランチの `/docs` を指定します。ビルドは不要です。

## データの更新

予定の本文は `docs/events-YYYY-MM.json` に月ごとにあります。日付や文章を変えるときは対象月のファイルを編集します。HTML には本文を書きません。

コンセンサスの数値がその時点で公開されていなければ「未発表」と書きます。公式の一次情報で日付を確認できない予定はグリッドに入れません。日付未確定のもの（Anthropic IPO、日付未確定の決算）は未確定枠だけに置き、日付が確定したら該当日のマスへ移します。

## skill の使用方法

更新手順はプロジェクト用の skill `.agents/skills/calendar-update/` にまとめています。skill の範囲はデータ更新のみで、見た目の変更や月切替の実装は含みません。

## 各月の新規作成方法

1. 前月の `docs/events-YYYY-MM.json` を複写して対象月のファイルを作ります。
2. 対象リストを確定します。固定枠は Amazon と Tesla、変動枠は NASDAQ 上場かつ GICS 情報技術セクターの時価総額上位50社を月初時点で固定します。
3. 各イベントの日付を一次情報（BLS、ISM、連邦準備制度、各社 IR、内閣府、総務省統計局、選挙の公式日程）で確認します。日付を確認できないものはグリッドに入れず、未確定枠に置きます。
4. 4項目（予想・上振れ・下振れ・持越）を各1〜2文で埋め、`asOf` を更新日に合わせます。

## 既存月の更新方法

1. 各イベントの日付を一次情報で再確認し、変わっていれば修正します。
2. 「未発表」のコンセンサスに、その時点で公開された市場予想があれば数値を入れます。
3. 未確定枠の銘柄の日付が確定したら、`unconfirmed` から抜いて `events` の該当日に移します。ID は変えません。
4. `asOf` を更新日に合わせます。

