# 2026年11月 米国市場スイングカレンダー

S&P500、米国個別株、ETF、インデックスファンドをスイングトレードするときに、2026年11月の予定と、その市場コンセンサス、S&P500への典型的な影響を PC で確認する静的サイトです。

株価やニュースの生配信はありません。画面は日本語です。カレンダーのマスは日本時間の日付で、各予定に日本時間（JST）、米国市場日、米東部時間（ET）を併記します。

## 使い方

ブラウザで `docs/index.html` を開きます。月グリッドの日マスを選ぶと、その日の予定がモーダルダイアログで開きます。閉じるには × ボタン、背景クリック、Esc のいずれかを使います。

`?month=YYYY-MM` を付けると、対応する `events-YYYY-MM.json` を相対パスで読み替えます（例: `index.html?month=2026-11`）。ファイルが無い、または月形式でない場合は `events-2026-11.json` を読みます。

Anthropic IPO など日付未確定のイベントは、グリッドの直後に未確定カードとして常時表示します。各カードは `details` で初期状態は閉じており、見出しに期間（`window`）と「日付未確定」を出します。日付が確定したら該当日のマスへ移します。

ローカルで見る場合は、`docs/` を配信します。`file://` では月ファイルを読めません。

```bash
cd docs
python3 -m http.server 8080
```

ブラウザで http://127.0.0.1:8080/ を開きます。

GitHub Pages で公開する場合は、`main` ブランチの `/docs` を指定します。ビルドは不要です。

## 画面の構成（現在の実装）

上から順に、ページ見出し、月グリッド、未確定カード、凡例、略語の解説、免責の順です。詳細はモーダル表示で、常設の右ペインはありません。

- グリッド: 月曜始まり・7列・42マス（6週）。対象月以外は非表示の空マスです。土日は背景と日付色で区別し、終日休場（`jstTime` が `null` の `market`）の日はさらに休場色になります。
- 各マス: 上部に日付と種別ドット（その日の種別を重複なく並べたもの）、下部に最大6件のチップを2列グリッドで表示します。チップ名は短縮名（ISM製造業、Apple決算、中間選挙、雇用統計、CPI、FOMC議事要旨、OPEX満期、感謝祭・休場、ブラックフライデー、早期終了）で、正式名はツールチップに出ます。7件目以降は「+N件」と出します。表示順は政治、経済指標、決算、市場、IPOの順です。
- 凡例: グリッドの直後ではなく、未確定カードの下にあります。種別名は「決算」「経済指標」「政治・選挙」「市場・取引時間」「IPO（新規上場）」です。
- 略語の解説: 凡例の下にあり、ISM、CPI、FOMC、OPEX、S&P 500、ET、JST を説明します。
- 詳細モーダル: 見出しは「M月D日（曜）」のみです。各イベントに「日本時間（JST） M月D日（曜） 時刻|終日 / 米東部時間（ET） M月D日（曜） 時刻|終日」、予想、上振れ、下振れ、持越、出典の順で出します。予定のない日は「この日の予定はありません」とだけ出します。
- ページ末尾の免責は固定文で、情報時点（`asOf`）を同じ領域に出します。

## データの更新

予定の本文は `docs/events-YYYY-MM.json` に月ごとにあります。日付や文章を変えるときは対象月のファイルを編集します。HTML には本文を書きません。

トップレベルは `asOf`（`YYYY-MM-DD`、ページに表示）、`timezone`（`Asia/Tokyo`）、`month`（`YYYY-MM`）、`unconfirmed`、`events` です。

- 確定イベントの項目: `id`、`jstDate`、`jstTime`（終日は `null`）、`usMarketDate`、`etTime`（終日は `null`）、`name`、`category`、`consensus`、`upside`、`downside`、`swing`、`sourceUrl`、`sourceName`。
- 未確定イベントの項目: `id`、`name`、`window`（表示用の期間文言。例: 「2026年11月上旬」）、`confirmed`（`false`）、`category` ほか4項目と出典。日付項目（`jstDate` など）は持ちません。

コンセンサスの数値がその時点で公開されていなければ「未発表」と書きます。公式の一次情報で日付を確認できない予定はグリッドに入れません。日付未確定のものは未確定枠だけに置き、日付が確定したら該当日のマスへ移します。

2026年11月分の収録内容（現在の `docs/events-2026-11.json` が正）:

- 固定枠: 米国 ISM 製造業景気指数、Apple 決算（電話会議）、米国中間選挙、米雇用統計（10月分）、米国消費者物価指数（10月分）、FOMC 議事要旨（10月27–28日会合）、月次オプション満期、感謝祭の米国市場休場、ブラックフライデー、感謝祭翌日の早期終了。
- 変動枠（決算）: マグニフィセント7（Alphabet、Apple、Meta、Amazon、Microsoft、Tesla、NVIDIA）と、月初時点で GICS の Information Technology セクターの時価総額上位50社から、該当月に決算が見込まれる銘柄。一次情報で確認できたものは確定、推定日に裏付けがあるものは「推定」表示でグリッドに置きます。
- 未確定: Anthropic IPO、Cisco 決算。ブラックフライデーは経済指標（`macro`）区分、早期終了・休場・OPEX 満期は市場（`market`）区分です。NVIDIA 決算は11月17日の電話会議が会社発表済みのため確定枠に移しました。
- 変動枠の追加（11月第1週の裏付け調査による）: Palantir 決算（11月2日・推定）、AMD 決算（11月3日・推定）、Qualcomm 決算（11月4日・会社告知済み）、Arm 決算（11月4日・推定）。

対象銘柄リストは `docs/universe-YYYY-MM.json`（現存は `docs/universe-2026-11.json` のみ）にあり、ページ最下部（略語の解説の下）に「対象銘柄と決算月」として折りたたみ表示されます。Mag7と、月初時点の GICS 情報技術セクター時価総額上位50社（順位は概算）の平常の決算月と今月の扱いを出します。

## skill の使用方法

更新手順はプロジェクト用の skill `.agents/skills/calendar-update/` にまとめています。skill の範囲はデータ更新のみで、見た目の変更や月切替の実装は含みません。

## 各月の新規作成方法

1. 前月の `docs/events-YYYY-MM.json` を複写して対象月のファイルを作ります。
2. 対象リストを確定します。2026年11月分は上記の収録内容が正です。変動枠の決算は、マグニフィセント7と月初時点の GICS 情報技術セクター時価総額上位50社から該当月に決算が見込まれる銘柄を入れます。
3. 各イベントの日付を一次情報（BLS、ISM、連邦準備制度、各社 IR、選挙の公式日程、NYSE 休日カレンダー、OCC 満期カレンダー）で確認します。一次情報で確認できない決算は、推定日に裏付けがあれば推定日でグリッドに置き（`estimated: true`、チップとモーダルに「推定」表示）、裏付けがなければ未確定枠に置きます。
4. 4項目（予想・上振れ・下振れ・持越）を各1〜2文で埋め、`asOf` を更新日に合わせます。

## 既存月の更新方法

1. 各イベントの日付を一次情報で再確認し、変わっていれば修正します。
2. 「未発表」のコンセンサスに、その時点で公開された市場予想があれば数値を入れます。
3. 未確定枠の銘柄の日付が確定したら、`unconfirmed` から抜いて `events` の該当日に移します。ID は変えません（未確定 ID と確定 ID が別体系の場合は確定側の ID に合わせます）。
4. `asOf` を更新日に合わせます。
